# Tableau Sales Analysis Dashboard

## Overview
This Tableau dashboard project analyzes Superstore sales data to identify category performance and geographic sales trends across the United States.

## Dashboard Features
- Sales by Category Analysis
- State-wise Sales Visualization
- Interactive Geographic Map
- Business Performance Insights
- Retail Sales Trend Analysis

## Key Insights
- Technology generated the highest sales
- Furniture and Office Supplies showed competitive performance
- Certain U.S. states contributed significantly higher sales volumes
- Geographic visualization helps identify regional business opportunities
